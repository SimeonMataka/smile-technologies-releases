# Smile Technologies — Staff App

Android app downloads for the **Smile Technologies** workshop team, Blantyre, Malawi.

This repository exists only to host the installable app files. It contains no source code.

> **For our team.** The app needs a staff account to sign in. If you don't have one,
> speak to your administrator.

---

## Download the latest version

**[→ Get the latest release](../../releases/latest)**

Download the `.apk` file listed under **Assets**.

---

## Installing

Because the app is distributed directly rather than through the Play Store, Android
will ask for permission the first time.

1. Open the downloaded `.apk` from your notifications or your **Downloads** folder.
2. Android will warn that it's from an unknown source — tap **Settings**, then turn on
   **Allow from this source**, and go back.
3. Tap **Install**, then **Open**.

Installing a newer version over an older one keeps you signed in and keeps all your
data. You do **not** need to uninstall first.

**Requirements:** Android 7.0 (Nougat) or newer.

---

## Updating

The app updates itself in the background for most changes — you'll occasionally be
asked to restart to apply one.

Some changes can't be delivered that way and need a new file from this page. When that
happens the app will tell you, with a **Download update** button that brings you here.

You can check at any time: **Profile → App version → Check for updates**. That screen
also shows which version you're currently running, which is useful if you're reporting
a problem.
